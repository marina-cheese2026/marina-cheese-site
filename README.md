# Сайт сыроварения

Рабочая страница находится в `index.html`. Все фотографии, используемые страницей, лежат рядом в `images/`.

## Git и публикация

Локальный git-репозиторий в этой папке уже создан (`git init`, первый коммит сделан). Дальше:

1. Создать пустой репозиторий на github.com (вручную — `gh` CLI не установлен).
2. `git remote add origin <ссылка на репозиторий>` и `git push -u origin master`.
3. Публикация — на домен на **Beget** (хостинг и домены уже оплачены и используются), а не на технический адрес vercel.app. Два рабочих варианта:
   - **Прямая заливка на Beget**: index.html + images/ через файловый менеджер/FTP хостинга Beget — без Vercel, проще для одного лендинга.
   - **GitHub + Vercel + свой домен**: деплой через Vercel (см. `knowledge/aibasis-html-to-page-knowledge.md`), затем в панели Beget прописать DNS-записи (A/CNAME), которые выдаст Vercel при подключении custom domain.
4. Перед публикацией пройти чек-лист из гайда: оплата/путь заказа, адаптив под телефон, безопасность, свой домен, юридические документы (см. `policy-vozvrat-oplata.md`).

Подробности методики — `knowledge/aibasis-html-to-page-knowledge.md` в корне проекта.
